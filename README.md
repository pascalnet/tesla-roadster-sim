# Tesla Roadster (2026) – Thrust & Rocket Simulator

A single-file, offline-capable (three.js r158 inlined) browser driving sim of the next-gen Tesla Roadster revealed 15 Oct 2026, with the SpaceX cold-gas thruster package (N₂ COPV pressure/temperature, per-nozzle firing), suction fans, active aero, tri-trim selection and a full telemetry HUD.

**Play:** https://pascalnet.github.io/tesla-roadster-sim/

Controls: W/S or arrows to drive, A/D to steer, Space for rear thrusters, F for lift/hover (Rocket), Q/E for yaw nozzles, Shift for launch mode, C for camera, X for TC, V for aero, G for fans, N for drive mode, K for compressor, P for pit, U for units, R to reset, M to mute. On touch screens you get on-screen pedals, steering and tilt. Gamepads are supported.

Specs come from tesla.com/roadster and posts on X from 15–16 Oct 2026. Values marked EST in the in-game spec table are labelled estimates. This is a fan project and is not affiliated with Tesla or SpaceX.
